# Opportunity Analytics System
The Opportunity Analytics System is a full-stack web application developed to help users manage and track various types of opportunities such as jobs, internships, sales leads, investments, and projects. The system provides role-based access, allowing different users (Student, Sales Head, Investor, Project Manager) to manage opportunities relevant to their domain. Users can add, view, edit, and delete opportunities, track their status, set deadlines, and record important details such as value and description. The application also provides an organized dashboard view to monitor opportunity progress and status. This system helps users efficiently track and manage opportunities in a structured and centralized manner.

## Technologies Used
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT (JSON Web Token)
- Styling: CSS

## Features
- User Login and Authentication
- Role-Based Opportunity Management
- Add New Opportunities
- Edit Existing Opportunities
- Delete Opportunities
- View All Opportunities in Table Format
- Track Status and Deadlines

## Setup
1. Clone: `git clone https://github.com/jananishankar567/Opportunity_Analytics_System.git`
2. Install: `cd client && npm install` then `cd ../server && npm install`
3. Create .env files (see .env.example).
4. Run: Client - `npm start`, Server - `node server.js`.
